# 🏡 HomeVista 3D

> **HomeVista 3D is an AI-powered real estate platform that combines immersive 3D property exploration, intelligent plot recommendations, interactive home customization, and real-time cost estimation to redefine the home-buying experience.**

## ✨ Features

### 🏘️ Interactive 3D Master Plan

* Real-time 3D housing scheme visualization
* Smooth zoom, pan, and orbit camera controls
* Interactive plot selection
* Live plot availability (Available, Premium, Reserved, Sold)
* Dynamic pricing and plot information

### 🏡 Home Configuration

* Multiple residential plot sizes
* Architectural footprint selection
* Live 3D home visualization
* Interactive home customization

### 🎨 Interior & Material Customization

* Premium wall finishes
* Luxury flooring options
* Furniture customization
* Landscaping personalization
* Swimming pool customization
* Real-time material previews
* Dynamic pricing updates

### 🤖 AI Plot Advisor

Powered by **Google Gemini AI**

* Smart property recommendations
* Budget-based plot matching
* Investment insights
* ROI-focused suggestions
* Personalized home recommendations

### 📊 Investment Estimator

* Live construction cost estimation
* Structural and interior cost breakdown
* Landscaping estimates
* Premium upgrade pricing
* Downloadable PDF quotations

## 🚀 Getting Started

### Prerequisites

* Node.js 18+
* npm

### Installation

```bash
git clone https://github.com/your-username/homevista-3d.git

cd homevista-3d

npm install
```

### Environment Variables

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

### Run the Application

```bash
npm run dev
```

Visit:

```text
http://localhost:5173
```

HomeVista 3D transforms traditional property browsing into an immersive digital experience.
